**Criador:** John Dimitry

## Como executar
1. Extraia `Aventuras_de_DiVinti_v3.zip`.
2. Abra `index.html` no Chrome, Firefox, Edge ou Opera.
3. Para editar o código, abra a pasta no VS Code. Não é necessário instalar engine ou banco de dados.
4. Se preferir, use uma extensão de servidor local, mas não é obrigatório.

## Arquivos
- `index.html`: estrutura, telas, botões, área do jogo, loja e apoio Pix.
- `style.css`: aparência responsiva em vermelho, preto e branco.
- `game.js`: mecânicas, controles, obstáculos, moedas, loja, missões, conquistas e salvamento.
- `README.md`: documentação do projeto.

## Comandos
- **Espaço** ou **seta para cima:** pular.
- **Seta para baixo:** deslizar.
- **P** ou **Esc:** pausar/continuar.
- **Enter:** iniciar ou reiniciar quando a corrida não está ativa.
- **M:** reservado para controle de som; os efeitos sonoros ainda não foram implementados.
- **Celular:** botão PULAR ou toque na área do jogo; botão DESLIZAR para se abaixar.

## Funcionalidades implementadas
- Corrida infinita com velocidade progressiva.
- Quatro famílias de obstáculos: caixas, placas, espinhos e barreiras altas.
- Vidas, pontuação, distância, recorde e efeitos de partículas.
- Moedas coletáveis: ao terminar a corrida, são adicionadas ao banco.
- Loja com sete personagens cosméticos desbloqueáveis.
- Escudo consumível: custa 80 moedas e bloqueia uma colisão na próxima corrida.
- Seis missões com recompensas em moedas.
- Seis conquistas com critérios de desbloqueio.
- Salvamento local de moedas, recordes, personagens, missões e conquistas com `localStorage`.
- Link do Instagram e área de apoio Pix com botão para copiar a chave.

## Sistema de moedas
1. Colete moedas douradas durante as corridas.
2. Quando a corrida termina, as moedas vão para o saldo.
3. Abra **Loja** para comprar e equipar personagens.
4. Compre um escudo por 80 moedas para proteger uma colisão na próxima corrida.
5. Complete missões para receber recompensas adicionais.
